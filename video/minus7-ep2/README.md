# «Этаж −7. Часть 2»

61 секунда, 1080×1920, 30 fps. Готовый файл: `renders/minus7-ep2.mp4`. Продолжение `../minus7`.

**Сюжет.** Ты оборачиваешься — никого. Но на мониторе он всё ещё за твоей спиной и теперь смотрит
в камеру. Экран гаснет: в чёрном стекле твоё отражение — и его. Ты бежишь к лифту, жмёшь «1»,
лифт едет вверх… ноль, остановка. Двери открываются в тот же коридор, на стене свежая царапина,
а под твоими ногтями — бетонная пыль. «Сколько раз ты уже здесь был?»

## Как пересобрать

```bash
cd video/minus7-ep2
python3 tools/build.py            # вставить героя/коридор в сцены с маркерами (уже вставлены)
bash tools/voice.sh && bash tools/mix.sh
npx hyperframes check
npx hyperframes render -o renders/minus7-ep2.mp4 --quality delivery
```

Реплики с пометками подачи — `voice-lines.tsv`, тайминг — `voice-timing.txt`.
