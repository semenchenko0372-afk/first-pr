# Следующий шаг: озвучка через Magnific (ElevenLabs)

Задача для новой сессии с подключённым коннектором Magnific (`https://mcp.magnific.com`)
или с ключом API в переменной окружения `MAGNIFIC_API_KEY`.

## Что сделать

1. Подобрать 2–3 голоса ElevenLabs, которые хорошо звучат по-русски: низкий, тихий, «ночной»
   рассказчик для хоррора. Сделать пробу на фразах 2, 9 и 17 из `voice-lines.tsv`,
   отдать на выбор.
2. Выбранным голосом озвучить все 21 фразу из `voice-lines.tsv` (по одной фразе на запрос).
   Через API это `POST https://api.magnific.com/v1/ai/voiceover/elevenlabs-turbo-v2-5`
   (заголовок `x-magnific-api-key`), задача асинхронная: опросить `GET /v1/ai/voiceover/{task_id}`
   и скачать файл из `generated`. Начальные настройки: `stability` 0.3 (живее), `similarity_boost` 0.6,
   `speed` 0.9; для шёпота (фразы 10–12, 18–20) — отдельный тихий/шепчущий голос, если найдётся.
   Подсказки по подаче каждой фразы — в `NACHITKA.md`.
3. Сохранить как `assets/voice/p01.mp3 … p21.mp3`, проверить каждую фразу распознаванием речи.
4. Длительности новых фраз отличаются от старых: пересчитать `voice-timing.txt`, субтитры
   в `compositions/captions.html`, окна сцен в `index.html` и точки звуков в `tools/mix.sh`,
   чтобы картинка шла под голос.
5. `bash tools/voice.sh && bash tools/mix.sh`, `npx hyperframes check`, снапшоты, рендер,
   сжатие до ~5 Мбит/с (как `renders/minus7.mp4`), коммит и пуш в эту же ветку.
6. В `CREDITS.md` записать, что голос — ElevenLabs через Magnific.

Расход: каждый запрос списывает кредиты Magnific (API всегда на кредитах, даже при «безлимитном» тарифе в веб-версии).
