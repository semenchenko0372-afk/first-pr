# Озвучка книги женским голосом

Превращает книгу в формате `.txt` в аудиокнигу (mp3). Читает нейроголос **Светлана**.
Это бесплатно, видеокарта не нужна, нужен только интернет.

Как звучит голос, можно послушать в файле `primer_golosa.mp3`.

## Как пользоваться (Windows)

1. Скачайте эту папку: на GitHub нажмите зелёную кнопку **Code → Download ZIP** и распакуйте архив.
2. Откройте папку `audiokniga`.
3. Перетащите мышкой файл книги (`.txt`) **на файл `OZVUCHIT.bat`**.
4. Если Python ещё не установлен, программа установит его сама и попросит перетащить книгу ещё раз.
5. Ждите. Рядом с книгой появится папка с её названием, а в ней файлы `001.mp3`, `002.mp3`, …
   Слушайте их по порядку.

Если интернет пропал или окно закрылось, просто перетащите книгу ещё раз.
Готовые части сохранятся, и озвучка продолжится с места остановки.

## Настройки

Откройте `ozvuchka.py` в Блокноте:

- `RATE = "-5%"` — скорость чтения. `"-10%"` медленнее, `"+0%"` обычная.
- `CHUNK = 20000` — размер одной части (около 20 минут звука).

## Важно

- Голос работает через сервис Microsoft, поэтому текст книги отправляется туда.
  Для личного прослушивания это нормально. Если хотите публиковать или продавать
  аудиокнигу, сначала проверьте условия Microsoft.
- Если слово читается с неправильным ударением, замените его в тексте синонимом
  или напишите по-другому.
