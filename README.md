# first-pr

Учебный репозиторий для первого pull request.

## Как использовать

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/semenchenko0372-afk/first-pr.git
   ```

2. Создайте ветку для своих изменений:

   ```bash
   git switch -c my-change
   ```

3. Внесите правки, сделайте коммит и отправьте ветку на GitHub:

   ```bash
   git add .
   git commit -m "Описание изменений"
   git push -u origin my-change
   ```

4. Откройте pull request в ветку `main` на GitHub.
