# Дубляж записи на английский

Скрипты, которыми озвучивается запись: английская речь остаётся оригинальной,
остальная речь переводится и озвучивается по-английски (Kokoro).

1. `sep.py` — отделяет голоса от фона (Demucs): `vocals.wav`, `background.wav`.
2. `relang.py` — находит реплики и определяет их язык (faster-whisper).
3. `score_lang.py` — уточняет язык каждой реплики: распознаёт её на en/ru/zh/th и берёт самый уверенный вариант.
4. Перевод реплик на английский → `plan.json` (`start`, `end`, `text`, `voice`).
5. `mix_dub.py` — озвучивает перевод и сводит его с оригинальным фоном.

`kokoro_say.py` и `kokoro_drama.py` озвучивают обычный текст (книги) голосами Kokoro.
